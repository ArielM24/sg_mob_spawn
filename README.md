# Synchro Games Mob Spawns

A mod that adds mob spawns for higher difficulty like illusioners, zombie horses, cave spiders, etc.

### Instalation

This mod is only compatible with fabric loaders

### Compatibility

Minecraft 1.21.5

### Requirements

Java 21
Fabric >=0.16.10
